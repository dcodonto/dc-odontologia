DC Odontologia Especializada - GitHub Pages

Como publicar:

1. Crie um repositorio no GitHub, por exemplo: dc-odontologia.
2. Envie para o repositorio todo o conteudo desta pasta:
   - index.html
   - styles.css
   - app.js
   - pasta assets
3. No GitHub, entre em Settings > Pages.
4. Em Source, escolha Deploy from a branch.
5. Escolha a branch main e a pasta /root.
6. Salve.

O link ficara parecido com:
https://seuusuario.github.io/dc-odontologia/

Para remover tambem o nome github.io, sera necessario conectar um dominio proprio.
